## Tag syntax by platform

- X: `@handle` inline. Mentions at the very start of a post turn it into a reply-style post with reduced reach; start with words, mention mid-sentence or at the end.
- LinkedIn: plain text cannot carry a tag. Write `TestMu AI` and `OpenAI` as text and add a line in the handover: "when pasting, type @ then the name and pick the page so it becomes a tag". Same for teammates.
- Hacker News: no tagging. Name the tools in prose.
- Blog: link, do not tag. First mention of each product links to its home page.

## Language about OpenAI

OpenAI asked for "association", not "partnership". Allowed:

- "built with OpenAI", "built on the OpenAI API", "using GPT-5.x via the Responses API", "Codex wrote the first draft of the parser"
- "Kane CLI Hack Day" is the event name; OpenAI is a supporter. Never "Kane CLI x OpenAI Hack Day"

Not allowed:

- "in partnership with OpenAI", "OpenAI-backed", "sponsored by OpenAI", "OpenAI approved", anything suggesting OpenAI reviewed or endorses the project
- Using the OpenAI logo in the deck or video without checking the event's brand guidance; the wordmark in text is fine

## Language about Kane CLI

Describe what it did, in verbs: ran, opened, clicked, asserted, failed, passed, sealed an evidence pack. The phrase "tested with Kane CLI" is the standard credit. "Verified by Kane CLI" is acceptable only when a run passed on the submitted SHA.
